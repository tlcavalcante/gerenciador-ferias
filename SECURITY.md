# Política de Segurança

Não publique neste repositório bancos de dados, backups, credenciais, tokens ou dados pessoais reais.

Para reportar uma vulnerabilidade de segurança, abra uma issue apenas quando a informação não contiver dados sensíveis. Para vulnerabilidades que possam expor dados ou credenciais, utilize um canal privado definido pelos mantenedores do projeto.
