# Código de Conduta

Este projeto adota um padrão de colaboração profissional, técnica e respeitosa.

Não serão tolerados assédio, discriminação, ameaças, ataques pessoais ou comportamento deliberadamente abusivo em issues, pull requests, discussões ou outros espaços relacionados ao projeto.

Problemas de conduta podem ser reportados aos mantenedores do projeto.
